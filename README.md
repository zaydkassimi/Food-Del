# 🍔 Food Del

> A Modern React-Based Food Delivery Platform With Interactive Menu Browsing, Shopping Cart Functionality, And User Authentication.

---

## 📖 About

**Food Del** is a comprehensive food delivery web application built with React and modern web technologies. The platform features a responsive design that works seamlessly across all devices, offering users an intuitive interface to browse diverse food categories.

---

## ✨ Features

- 🍕 **Multi-category Menu** — Browse Pizza, Chicken, Tacos, Pasta, Couscous, Tajine, Fish, and Pastilla
- 🛒 **Shopping Cart** — Real-time cart management with quantity controls and price calculations
- 🔐 **User Authentication** — Login/logout functionality with secure session handling
- 📱 **Responsive Design** — Optimized for mobile and desktop
- 🎨 **Modern UI** — Smooth animations and transitions
- 🏠 **Professional Footer** — Company info and social links

---

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| **React.js** | Frontend framework |
| **React Router DOM** | Client-side navigation |
| **Vite** | Build tool & dev server |
| **CSS3** | Styling & animations |
| **Context API** | Global state management |
| **JavaScript ES6+** | Core logic |

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/zaydkassimi/Food-Del.git

# Navigate to the project
cd Food-Del

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open your browser and go to `http://localhost:5173`
